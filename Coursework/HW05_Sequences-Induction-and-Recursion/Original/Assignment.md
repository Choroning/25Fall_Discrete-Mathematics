## 1. Exercise 5.1.47: An Alternating Sum

Write the following expression using summation or product notation.

```math
1 - r + r^2 - r^3 + r^4 - r^5
```

## 2. Exercise 5.2.34: A Formula for a Geometric Sum

Find a formula in $a$, $r$, $m$, and $n$ for the following sum, where $m$ and $n$ are integers, $n \ge 0$, and $a$ and $r$ are real numbers. Justify your answer.

```math
ar^m + ar^{m+1} + ar^{m+2} + \cdots + ar^{m+n}
```

<br>

## 3. Exercise 5.3.5: An Inequality Between a Power and a Factorial

For each positive integer $n$, let $P(n)$ be the inequality $2^n < (n+1)!$.

- (a) Write $P(2)$. Is $P(2)$ true?
- (b) Write $P(k)$.
- (c) Write $P(k+1)$.
- (d) In a proof by mathematical induction that this inequality holds for every integer $n \ge 2$, what must be shown in the inductive step?

## 4. Exercise 5.6.8: Terms of a Recursively Defined Sequence

Find the first four terms of the following recursively defined sequence.

```math
v_k = v_{k-1} + v_{k-2} + 1 \quad (\text{for every integer } k \ge 3), \qquad v_1 = 1, \quad v_2 = 3
```
