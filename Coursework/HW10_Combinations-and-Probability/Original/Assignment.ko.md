  - (i) 여성 4명과 남성 3명으로 이루어진 7명의 그룹은 몇 가지 고를 수 있는가?

## 5. 연습 문제 9.7.10: 파스칼의 삼각형

교재의 표 9.7.1은 $n = 5$인 행까지의 파스칼의 삼각형으로, $n$행 $r$열에 $\binom{n}{r}$을 적은 표이다.

| $n$ \\ $r$ | 0 | 1 | 2 | 3 | 4 | 5 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 | 1 | | | | | |
| 1 | 1 | 1 | | | | |
| 2 | 1 | 2 | 1 | | | |
| 3 | 1 | 3 | 3 | 1 | | |
| 4 | 1 | 4 | 6 | 4 | 1 | |
| 5 | 1 | 5 | 10 | 10 | 5 | 1 |

*표 1. n = 5인 행까지의 파스칼의 삼각형*

- (a) 표 1의 파스칼의 삼각형을 이용하여 $\binom{6}{2}$, $\binom{6}{3}$, $\binom{6}{4}$, $\binom{6}{5}$의 값을 구하라.
- (b) (a)의 결과와 파스칼의 공식을 이용하여 $\binom{7}{3}$, $\binom{7}{4}$, $\binom{7}{5}$를 구하라.
- (c) 파스칼의 삼각형에서 $n = 7$에 해당하는 행을 완성하라.

## 9. 연습 문제 9.9.9: 두 사건에 대한 베이즈 정리

$n = 2$인 경우의 베이즈 정리를 증명하라. 곧 표본 공간 $S$가 서로소인 사건 $B_1$과 $B_2$의 합집합이고, $A$가 $P(A) \ne 0$인 $S$의 사건이며, $k = 1$ 또는 $k = 2$이면 다음 등식이 성립함을 증명하라.

```math
P(B_k \mid A) = \frac{P(A \mid B_k)\,P(B_k)}{P(A \mid B_1)\,P(B_1) + P(A \mid B_2)\,P(B_2)}
```

## 10. 연습 문제 9.9.20: 동전 던지기와 독립 사건

공정한 동전을 세 번 던진다고 하자. $A$를 첫째 던지기에서 앞면이 나오는 사건, $B$를 앞면이 짝수 번 나오는 사건이라 하자. $P(A \mid B) = P(A)$이고 $P(B \mid A) = P(B)$임을 보이라.
