## 2. 연습 문제 5.2.34: 등비 합의 공식

$m$과 $n$이 정수이고 $n \ge 0$이며 $a$와 $r$이 실수일 때, 다음 합을 $a$, $r$, $m$, $n$의 식으로 나타내라. 답의 근거도 쓰라.

```math
ar^m + ar^{m+1} + ar^{m+2} + \cdots + ar^{m+n}
```

## 3. 연습 문제 5.3.5: 거듭제곱과 계승의 부등식

각 양의 정수 $n$에 대해 $P(n)$을 부등식 $2^n < (n+1)!$이라 하자.

- (a) $P(2)$를 쓰라. $P(2)$는 참인가?
- (b) $P(k)$를 쓰라.
- (c) $P(k+1)$을 쓰라.
- (d) 2 이상인 모든 정수 $n$에 대해 이 부등식이 성립함을 수학적 귀납법으로 증명할 때, 귀납 단계에서 보여야 하는 것은 무엇인가?

## 4. 연습 문제 5.6.8: 재귀적으로 정의된 수열의 항

다음과 같이 재귀적으로 정의된 수열의 처음 네 항을 구하라.

```math
v_k = v_{k-1} + v_{k-2} + 1 \quad (k \ge 3\text{인 모든 정수 } k), \qquad v_1 = 1, \quad v_2 = 3
```
