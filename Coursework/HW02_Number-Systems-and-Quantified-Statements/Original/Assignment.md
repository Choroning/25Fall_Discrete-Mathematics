## 6. Exercise 3.1.2: Truth of Statements about Numbers

Indicate which of the following statements are true and which are false. Justify your answers as best as you can.

- (a) Every integer is a real number.
- (b) 0 is a positive real number.
- (c) For every real number $r$, $-r$ is a negative real number.
- (d) Every real number is an integer.

---

<br>

## 7. Exercise 3.1.4: Values That Make a Predicate False

Let $Q(x, y)$ be the predicate "if $x < y$ then $x^2 < y^2$", with domain for both $x$ and $y$ being the set $\mathbf{R}$ of real numbers.

- (a) Explain why $Q(x, y)$ is false if $x = -2$ and $y = 1$.
- (b) Give values different from those in part (a) for which $Q(x, y)$ is false.

---

<br>

## 8. Exercise 3.1.12: Disproving a Universal Statement by Counterexample

Find a counterexample to show that the following statement is false.

```math
\forall \text{ real numbers } x \text{ and } y,\quad \sqrt{x + y} = \sqrt{x} + \sqrt{y}
```

## 9. Exercise 3.1.17: The Form of Existential Statements

Rewrite each of the following in the form "$`\exists`$ \_\_\_\_ $x$ such that \_\_\_\_".

- (a) Some exercises have answers.
- (b) Some real numbers are rational.

---

## 10. Exercise 3.1.26: Combining Universal and Existential Statements

Consider the statement "All integers are rational numbers but some rational numbers are not integers".

- (a) Write this statement in the form "$`\forall x`$, if \_\_\_\_ then \_\_\_\_, but $\exists$ \_\_\_\_ $x$ such that \_\_\_\_".
- (b) Let $\text{Ratl}(x)$ be "$`x`$ is a rational number" and $\text{Int}(x)$ be "$`x`$ is an integer". Write the given statement formally using only the symbols $\text{Ratl}(x)$, $\text{Int}(x)$, $\forall$, $\exists$, $\wedge$, $\vee$, $\sim$, and $\to$.

---

<br>

## 11. Exercise 3.2.2: Negation of a Universal Statement

Which of the following is a negation for "All dogs are loyal"? More than one answer may be correct.

- (a) All dogs are disloyal.
- (b) No dogs are loyal.
- (c) Some dogs are disloyal.
- (d) Some dogs are loyal.
- (e) There is a disloyal animal that is not a dog.
- (f) There is a dog that is disloyal.
- (g) No animals that are not dogs are loyal.
- (h) Some animals that are not dogs are loyal.

---
